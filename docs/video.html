The problem

Security tools stop at detection: logs, alerts, dashboards, and human toil. Nobody proves a defense actually works before a real adversary tests it, and letting an AI change a firewall feels reckless — so automation stalls at recommendations while attackers adapt.

What you are watching

Everything shown was built during the Meta Global AI Developer Hackathon (Oct 26 – Nov 4, 2026). The recording is a live run: Meta Muse Spark 1.3 reasons in real time, accessed through the Command Code gateway.

  1. 0:15 The twin — a fully synthetic digital twin of an enterprise network, safe to attack.
  2. 0:33 Bring your own network — Muse Spark vision reads a network diagram and generates a twin, schema-validated before it is built.
  3. 0:52 Attack and reasoning — the Observer turns telemetry into evidence; Muse Spark investigates, citing the exact telemetry, and the Strategist proposes a defense from the attack graph alone, rehearsed on a cloned twin.
  4. 1:20 Guardrails — a deterministic policy engine (no LLM) validates every action; the high-impact defense waits for human approval; the AI has no shell, filesystem or network access.
  5. 1:46 Proof — an independent replay verifies PASS (risk 58% → 0%), with an Ed25519-signed certificate verifiable offline and a minimum-cut optimality proof. A failed defense is reported as FAIL, never hidden.
  6. 2:09 Arena, live — Muse Spark plays both red and blue among validated moves; the replay shows each round, the winner gets a signed proof, and the decision evidence shows the model's own reasoning.
